## 🔧 使用说明

每个课程实验目录下均包含该课程对应的实验代码和相关文档。具体构建与运行方式请参考各课程目录下的说明文件。

### 克隆仓库

```bash
git clone <repo-url>
cd <repo-name>
```

> **注意**：本仓库使用根级 `.gitignore` 统一忽略构建产物（`build/`、`*.o`、`*.a` 等），克隆后需按照各课程的说明重新编译。
